How it works

Idea in. Executable backlog out.

Three steps. Edit any of them before the next.

STEP 01

Plan

Say the idea. Answer a few questions. See the architecture.

  • Features and tech stack
  • Mermaid diagrams
  • Phased roadmap
STEP 02

PRD

A real PRD, sized for a first release.

  • Goals and scope
  • User stories with acceptance criteria
  • Risks and open questions
STEP 03

Task board

Small tasks, in order, each with a way to prove it is done.

  • Target files and dependencies
  • A verify command per card
  • Run one card or a whole phase
  • Export AGENTS.md for any agent

Day to day

Built for coming back tomorrow.

The project stays. The chats come and go.

Close the laptop. Not the project.

A folder holds the plan, the board and the memory. Open a new chat tomorrow and carry on.

Not just a prompt. A whole phase.

Chat with the agent as usual, or run a phase in one click: cards in order, stopping at the first one that fails.

“Done” has to prove it.

Every card carries a check. Exit 0 and it is Verified; no check and it is marked Unverified.

Every quota, one glance.

See what is left on Claude Code, Codex and Antigravity without spending any of it. Running low? Switch and keep going.

Install

Download the app, or run two commands.

No database to install: everything is one file on disk. Running the script again keeps your data/ and .env.

Desktop app

Installers for Windows (.exe) and Linux (.AppImage, .deb) are on the v1.0.6 release and bundle their own runtime. They are unsigned: on Windows, SmartScreen warns on first run (“More info”, then “Run anyway”).

LINUX

curl -fsSLO https://raw.githubusercontent.com/CharisChakim/undagi/main/install.sh
bash install.sh
undagi

WINDOWS POWERSHELL

Invoke-WebRequest https://raw.githubusercontent.com/CharisChakim/undagi/main/install.ps1 -OutFile install.ps1
